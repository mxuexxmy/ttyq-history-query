# TTYQ History Query

一个面向 Windows 的六场半全场历史数据查询工具，可查询期号、比赛结果、开奖详情，以及欧指、让球、进球数等公开赔率数据。

项目使用 Windows PowerShell 提供本地 HTTP 服务，浏览器通过 `http://127.0.0.1:26128/` 访问，不需要安装 Node.js、Python 或数据库。

## 功能

- 下拉选择历史期号，并自动识别官网已发布的最新期号
- 支持手动输入 5 位简写期号或 7 位完整期号
- 展示比赛时间、状态、球队、比分、半场比分和赛况
- 展示销量、奖池、一等奖注数及奖金等开奖详情
- 支持欧指、让球、进球数三类赔率切换
- 支持平均欧指及多个官方脱敏公司选项
- 欧指模式按比赛结果标记首赔、次赔、末赔并统计
- 支持隐藏牌数、隐藏赔率、打印或保存 PDF
- 未开赛比赛不着色、不计入欧指统计，比分显示为 `—`

## 运行环境

- Windows 8.1、Windows 10 或 Windows 11
- Windows PowerShell 3.0 或更高版本
- 可访问互联网的浏览器
- 网络需要支持 TLS 1.2

Windows 8.1 建议使用仍可运行的 Chrome、Edge 或其他 Chromium 浏览器。项目脚本避免使用现代 JavaScript 语法，并兼容 Windows PowerShell 3.0。

## 使用方法

1. 下载或克隆本项目。
2. 双击 `双击启动.cmd`。
3. 保留打开的 PowerShell 窗口。
4. 浏览器会自动打开 `http://127.0.0.1:26128/`。
5. 从下拉框选择期号，或切换到“手动输入”查询。
6. 关闭 PowerShell 窗口即可停止本地服务。

如果网页没有自动打开，可手动访问：

```text
http://127.0.0.1:26128/
```

## 期号格式

- 5 位简写：`26128`
- 7 位完整：`2026128`

5 位期号会自动转换为对应的 7 位完整期号。

## 赔率分类

接口中的 `type` 和 `provider` 对应如下：

| 分类 | type | provider |
| --- | --- | --- |
| 欧指 | `oz` | `0`–`5`、`7` |
| 让球 | `asia` | `0`–`5` |
| 进球数 | `dx` | `0`–`5` |

公司编号：

| provider | 页面名称 |
| --- | --- |
| `0` | 皇* |
| `1` | 36* |
| `2` | 澳* |
| `3` | 威廉* |
| `4` | 伟* |
| `5` | 立* |
| `7` | 平均欧指，仅欧指支持 |

默认使用 `type=oz&provider=7`。

## 本地接口

### 期号列表

```http
GET /api/issues
```

### 比赛与赔率

```http
GET /api/issue?issue=2026139&type=oz&provider=7
```

参数：

- `issue`：5 位或 7 位期号
- `type`：`oz`、`asia`、`dx`
- `provider`：对应赔率公司编号

### 开奖详情

```http
GET /api/draw?issue=2026139
```

## 常见问题

### 双击后窗口一闪而过

请确认项目文件完整，并通过 `双击启动.cmd` 启动。不要直接双击 `server.ps1`。

### 提示工具已经在运行

说明端口 `26128` 已被另一个本项目窗口占用。保留一个运行窗口即可。

### 页面仍是旧内容

关闭现有 PowerShell 窗口，重新双击启动文件。服务响应已禁用浏览器缓存。

### 某期没有赔率数据

官网可能尚未发布对应分类或公司的独立赔率文件，请更换分类、公司或稍后再试。

### Windows 8.1 无法联网

请确认系统已启用 TLS 1.2，且网络可以访问数据来源网站。
